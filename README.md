# Test Project

Node.js project intended to run TypeScript with Next.js.

## Tech stack

- **Runtime:** Node.js
- **Language:** TypeScript
- **Framework:** Next.js
- **Config:** dotenv

## Requirements

- Node.js (this repo has been used with v24)
- npm

On Windows PowerShell, if `npm` fails with an execution-policy error, use `npm.cmd` instead (for example `npm.cmd install`).

## Setup

```bash
npm install
```

## Status

The app has not been scaffolded yet. `package.json` currently has `dotenv` as a dependency. Next.js and TypeScript still need to be added.
